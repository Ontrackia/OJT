# Branding Standard: Morado Oscuro

The OnTrackIA platform follows a premium "Morado Oscuro" (Deep Purple) visual identity, designed for high-end aeronautical environments.

## 🎨 Color Palette

| Usage | Color Hex | CSS Variable |
| :--- | :--- | :--- |
| **Primary Background** | `#0a051a` | `--bg-primary` |
| **Secondary Background** | `#0f0a26` | `--bg-secondary` |
| **Primary Accent** | `#7c3aed` | `--theme-primary` |
| **Text (Hero)** | `#ffffff` | `--text-primary` |
| **Text (Dimmed)** | `#9ca3af` | `--text-secondary` |

## 📐 Layout Standards

### Clean Block Style

- **Glassmorphism**: 1px translucent borders and background blurs for dashboard cards.
- **Card Padding**: Optimized for mobile with vertical stacking on breakpoints < 768px.
- **Iconography**: Use of `lucide-react` with specific `strokeWidth={1.5}` for a technical look.

### Aeronautical Ergonomics

- **Touch Targets**: 44px minimum height/width for all buttons and interactive icons.
- **Font**: Clean Sans-Serif stack (Inter/Roboto) for maximum legibility in high-pressure environments.

## 🖼️ Identity Assets

- **Logo**: The checked OnTrackIA shield, used in Sidebar and Login.
- **Favicon**: Official purple logo integrated in `index.html`.
- **System Indicator**: Real-time Sync Status dot located in the Header.
